# Les Traîtres — Compagnon de jeu

Compagnon numérique pour le jeu de cartes officiel **Les Traîtres** (TOMY).

Le paquet, les mains et la cagnotte restent 100 % physiques — l'appli sert uniquement
à arbitrer les moments qui exigent du secret : distribution des rôles, votes
d'Assassinat et de Bannissement, recrutement d'un nouveau Traître.

## Utilisation

Ouvrez `index.html` dans un navigateur (ou la page publiée via GitHub Pages).
Chaque joueur regarde ses vraies cartes physiques puis les déclare en secret,
un par un, en se passant l'appareil.

## Fichiers

- `index.html` / `les-traitres.html` — l'application (identiques)
- `regles-vs-appli.html` — comparatif détaillé entre les règles officielles et leur traitement dans l'appli
